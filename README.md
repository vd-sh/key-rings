## Process

Each keyring was designed from scratch in Onshape, using basic shapes and text, then exported as a STEP file for 3D printing. Focused on keeping wall thickness and hole sizing practical for a functional, wearable keyring rather than just a decorative shape. Was harder for me to assume how the structures would behave while printing, but gave me an experience of how to think about printing too while building simultaneously.
